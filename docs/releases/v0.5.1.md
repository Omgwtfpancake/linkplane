# Linkplane v0.5.1 — first-run onboarding polish

Released 2026-09-13 as a GitHub pre-release (Linkplane is still in public alpha).

First alpha onboarding polish based on real-user feedback. Tester #1 installed v0.5.0 on
Arch/Omarchy, and everything worked, but three things were confusing. This patch fixes
exactly those. No device capability changes, no behaviour changes outside the setup
completion text.

## Changed

- **Setup completion suggestions run as printed.** v0.5.0 printed `linkplane send <file>`;
  typed as `linkplane send` it fails with an argument error. Setup now suggests, in this
  order: `linkplane notify "Hello from Linkplane"` (the moment the phone visibly answers),
  `linkplane status`, and a complete two-step example that creates a tiny file and sends
  it: `echo "Hello from Linkplane" > /tmp/linkplane-hello.txt && linkplane send
  /tmp/linkplane-hello.txt`.
- **One operating system per install section.** README, `docs/install.md`, the release
  notes and the tester guide now show the Arch/Omarchy and Ubuntu 24.04 prerequisite
  commands in separate sections with "run only one"; the previous single block led a
  tester to run `apt` on Arch.
- **`pipx ensurepath` only when needed.** The instructions now say to run it once only if
  `linkplane` is not found after installation, then open a new terminal.
- **Tester guide** first session: install, setup, notify, status, send a tiny file, watch
  events during a replug, doctor, setup again.

## Unchanged and worth knowing

- Wi-Fi is absent from `status` while the phone's Wi-Fi is off and appears, with a
  `wifi.connected` event, once it is on. That is by design.
- Everything in `docs/releases/v0.5.0.md` (supported platforms, Android requirements,
  privacy, known limitations) still applies.

## Install

Choose your operating system and run only that section.

Arch Linux / Omarchy:

```sh
sudo pacman -S --needed python-pipx android-tools android-udev
pipx install https://github.com/Omgwtfpancake/linkplane/releases/download/v0.5.1/linkplane-0.5.1-py3-none-any.whl
linkplane --version
```

Ubuntu 24.04:

```sh
sudo apt update
sudo apt install pipx adb
pipx install https://github.com/Omgwtfpancake/linkplane/releases/download/v0.5.1/linkplane-0.5.1-py3-none-any.whl
linkplane --version
```

If `linkplane` is not found afterwards, run `pipx ensurepath` once and open a new terminal.

Upgrading from v0.5.0: `pipx install --force <the wheel URL above>`, then `linkplane setup`
(it restarts a daemon that still runs the old version).
